# Charie’s Portfolio

Personal portfolio website for **Charity Michael (“Charie”)**, a Cybersecurity student at the Federal University of Technology Akure (FUTA) working toward a career in Quantum-Safe Engineering.

## Overview

The portfolio highlights Charie’s:

- Background and career direction: cybersecurity → quantum-safe engineering
- Core skills: Python, backend development, data analysis and AI, and post-quantum cryptography
- Projects and technical work
- Contact and professional links
- Résumé/CV download

## Project Structure

```text
.
├── frontend/         # React + TanStack Start application
│   ├── public/       # Static assets and downloadable files
│   ├── src/          # Application source code and portfolio content
│   └── index.html    # Application entry point
├── backend/          # Reserved for future server-side features
└── README.md         # Project documentation
```

## Development

Requires Node.js and npm.

```sh
cd frontend
npm install
npm run dev
```

The site will be available at `http://localhost:3000/` (or the port shown in your terminal).

## Purpose

This site serves as a professional overview of Charie’s experience, interests, projects, and long-term focus on building secure systems for the post-quantum era.
